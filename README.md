## 추천 코스

### 안동 (1순위, 2가지 코스안)

**A. 전통마을형**
안동역/터미널 집결 → 하회마을(부용대·병산서원) → 단체 식사 → 월영교 산책 → 귀가

**B. 서원·전통주형**
안동역/터미널 집결 → 도산서원 → 단체 식사 → 안동소주전시관(전통주 체험) → 귀가

| 장소 | 유형 | 비고 |
|---|---|---|
| 하회마을 | 전통마을 | 부용대·병산서원, A 코스 |
| 하회별신굿탈놀이 상설공연 | 전통공연 | 매주 화~일 14시, A 코스 옵션 |
| 월영교 | 산책로 | 야간 조명 명소, A 코스 |
| 도산서원 | 서원(역사) | B 코스 |
| 안동소주전시관 | 전통주 체험 | 시음·체험 프로그램, B 코스 |

[확인 필요] 하회별신굿탈놀이 공연, 안동소주전시관 체험은 요일·시간이 맞아야 하므로 날짜 확정 후 운영 여부를 전화로 확인해야 합니다.

### 문경 (대안, 2가지 코스안)

**A. 새재 둘레길형**
문경새재 입구 집결 → 주흘산·조령관문 둘레 산책 → 단체 식사 → 오미나라(오미자 와인 체험) → 귀가

**B. 에코월드 체험형**
문경에코월드 집결 → 가은오픈세트장(사극 촬영지 관람) + 은성갱도 석탄박물관(거미열차 탑승) → 단체 식사 → 귀가

| 장소 | 유형 | 비고 |
|---|---|---|
| 문경새재·조령관문 | 둘레길 산책 | A 코스 |
| 오미나라 | 전통주(오미자 와인) 체험 | A 코스 |
| 가은오픈세트장 | 사극 드라마 세트장 | B 코스, 왕궁·기와집 등 재현 |
| 은성갱도 석탄박물관 | 체험 전시(거미열차 탑승) | B 코스, 폐광 갱도 체험 |

[확인 필요] 가은오픈세트장·은성갱도는 문경에코월드 부지 내에 있어, 단체 입장권과 거미열차 탑승 인원을 사전 확인해야 합니다.

### 단양 (대안, 2가지 코스안)

**A. 가벼운 체험형**
단양역/터미널 집결 → 만천하스카이워크 전망대(모노레일로 이동) → 단양강 잔도 산책 → 단체 식사 → 단양구경시장 먹거리 투어 → 귀가

**B. 액티비티형**
단양역/터미널 집결 → 만천하스카이워크 전망대 → 짚와이어 체험 → 만천하 알파인코스터·슬라이드 체험 → 단체 식사 → 귀가

| 장소 | 유형 | 비고 |
|---|---|---|
| 만천하스카이워크 전망대 | 전망대(도보) | A·B 코스 공통 |
| 만천하 모노레일 | 전망대 이동수단 | 걷지 않고 편하게 오르내림, A 코스 |
| 단양강 잔도 | 강변 데크 산책로(1.2km) | 유네스코 세계지질공원 구간, 평탄 |
| 단양구경시장 | 전통시장 먹거리 | 마늘순대·마늘만두·흑마늘치킨 등 |
| 짚와이어(만천하) | 체험형 레저 (무동력 활강, 총 980m) | 알파인코스터보다 짧고 간단, B 코스 |
| 만천하 알파인코스터 | 체험형 레저 | B 코스 |
| 만천하 슬라이드 | 체험형 레저 | B 코스 |
| 구인사(단양) | 전통 사찰 | 단양군 영춘면 소재 |
| 단양 수양개빛터널 | 실내 전시 관람 | 폐터널 조명 전시, 짧고 가벼움 |

[확인 필요] 짚와이어·알파인코스터·슬라이드는 체중·신장 제한이나 안전 수칙이 있을 수 있어, 날짜 확정 후 시설 측에 단체 예약·참여 조건을 전화로 확인해야 합니다.
